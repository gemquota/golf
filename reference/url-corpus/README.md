# Archived URL research lists

These files are source/reference snapshots used during URL discovery and
classification. They are not the active scraper input. The live URL list is
`in/config/urls.txt`, which is maintained separately by the scraper lifecycle.

- `urls.txt`: broad extracted URL corpus.
- `slap_red_urls.txt` and `non_slap_red_urls.txt`: manually classified URL sets.
- `extracted_from_csv.txt`: URL extraction from a CSV source.
- `mapped_urls.csv`: short-URL mapping and match-status results.

Keep provenance distinctions between these files. Their overlap is
intentional and they are not interchangeable inputs.
