# Golf bonus viewer

Static Vite dashboard for the bonus scraper's published CSV snapshots and release-history data.

**Live site:** https://gemquota.github.io/golf/

## Published data

The files in `public/` are generated by the scraper/export pipeline and are committed because GitHub Pages serves them as static assets:

- `dayne-bonuses.csv` — current raw bonus records.
- `dayne-bonuses-cleaned.csv` — positive-amount, deduplicated records.
- `dayne-bonuses-all.csv` — expanded records with scoring and history fields.
- `dayne-sites.csv` — per-site activity and value rollups.
- `bonus-history.json` — durable daily observations and release analytics.

These are distinct data contracts, not duplicate exports.

## Build

```sh
npm ci
npm run build
```

GitHub Actions deploys the built site to Pages when viewer assets or the deployment workflow change on `main`.
